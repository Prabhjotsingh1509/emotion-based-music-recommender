# Emotion-Based Music Recommender System

An emotion-based music recommendation system built with Python and machine learning. The project predicts a user's emotion and recommends songs based on the detected emotion.

## Features

- Emotion classification using machine learning
- Music recommendations based on predicted emotion
- Graphical user interface built with Python
- Dataset-driven recommendation workflow

## Technologies

- Python
- Machine Learning
- Tkinter
- Pandas
- Scikit-learn
- TF-IDF / text-based features


## How to Run

1. Clone the repository.
2. Install the required Python packages from `requirements.txt`.
3. Run the GUI using `python gui.py`.
